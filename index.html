Foundations
AI / ML / DL / GenAI relationships, discriminative vs generative modelling, language modelling, model vs application (stateless calls, memory, testing), kinds of models, training vs fine-tuning vs inference, model size and licences, a short history and perplexity.
Milestone: explain how a GenAI app differs from a prediction pipeline.
Written

How LLMs work

Milestone: Python experiments that link model mechanics to behaviour.

Milestone: a Python assistant with validation and error handling.
Planned
4
Working with your data

Milestone: build and evaluate a document Q&A app.
Planned
5
Agents and workflows
Workflows vs agents, tool execution, state, memory, orchestration, persistence, approvals, recovery.
Milestone: a bounded assistant that completes a multistep task.
Planned
6
Advanced development
Evaluation, fine-tuning, LoRA / QLoRA, security, observability, cost, latency, deployment, monitoring.
Milestone: test, improve and deploy a complete application.
